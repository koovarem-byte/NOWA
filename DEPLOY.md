# Как выложить NOWA в интернет (без VPN для пользователей из России)

Нужно две вещи: **сервер для приложения** и **база PostgreSQL**. Оба — у хостинга,
который в России не блокируется. Ниже пример для Timeweb Cloud; у Selectel и
Yandex Cloud шаги почти такие же (везде есть «приложение из Docker» и «управляемая PostgreSQL»).

## 1. База данных

1. Создай аккаунт на timeweb.cloud.
2. «Базы данных» → «Создать» → PostgreSQL, самый маленький тариф.
3. Скопируй строку подключения вида `postgresql://user:password@host:5432/default_db`.

## 2. Приложение

1. «Apps» → «Создать» → Docker → подключи GitHub и выбери репозиторий `nowa`,
   ветку с кодом. Dockerfile лежит в корне — хостинг найдёт его сам.
2. Переменные окружения:

   | Переменная     | Значение                                                    |
   |----------------|-------------------------------------------------------------|
   | `DATABASE_URL` | строка подключения из шага 1                                |
   | `SECRET_KEY`   | длинная случайная строка (`python -c "import secrets; print(secrets.token_hex(32))"`) |
   | `NOWA_HTTPS`   | `1` (когда сайт открывается по https)                       |
   | `VAPID_PRIVATE_KEY` | ключ для пуш-уведомлений: `python web/webpush.py` напечатает готовую строку |
   | `VAPID_SUBJECT` | `mailto:твоя@почта` — контакт для сервисов доставки пушей  |
   | `NOWA_ADMINS`  | имена модераторов через запятую, им откроется `/admin/reports` |

3. Проверка здоровья (health check): путь `/health`.
4. Запусти деплой. Таблицы в базе создадутся сами при первом запуске.

## 3. Перенос старых данных

Один раз, со своего компьютера:

```bash
pip install -r web/requirements.txt
DATABASE_URL="строка-из-шага-1" python web/import_old_data.py
```

## 4. Свой домен (по желанию)

Купи домен (например, на reg.ru), в настройках приложения добавь его,
а у регистратора пропиши DNS-запись, которую покажет хостинг. HTTPS-сертификат
хостинг выпустит сам.

## Важно

- **`VAPID_PRIVATE_KEY` задай один раз и не меняй**: если ключ поменяется, у всех слетят
  подписки на уведомления и их придётся включать заново.
- Пуш-уведомления работают только по https (на хостинге это включается само).
  На iPhone они приходят, только если NOWA добавлена на экран «Домой».

- **SQLite на сервере не используй**: файл базы пропадёт при каждом перезапуске контейнера.
- Фото хранятся в базе, поэтому отдельное хранилище настраивать не нужно.
- Публичная соцсеть с аудиторией из России попадает под российские законы о хранении
  данных и реестр ОРИ. Пока проект маленький, это не критично, но знать об этом стоит.
