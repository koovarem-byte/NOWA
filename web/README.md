# NOWA — что сейчас?

Соцсеть для своих, которая выводит в жизнь, а не держит в телефоне.
Открывается в любом браузере, ставится на телефон как приложение (PWA),
не требует номера телефона. Стратегия и разбор конкурентов — в [docs/STRATEGY.md](../docs/STRATEGY.md).

## Что уже есть

- 🔆 **Маяки** — «я свободен сейчас, кто со мной?»: полоса «Сейчас» в ленте, «Я в деле!»,
  чат маяка, который исчезает, когда маяк гаснет. Место встречи видят только участники
- 📤 Ссылка на маяк для любого мессенджера, с превью; пришедший по ней регистрируется
  и сразу попадает в маяк и в друзья к автору
- 💌 Личная ссылка-приглашение: новичок сразу в друзьях у пригласившего
- 💭 **Вопрос дня**: ответы друзей открываются после своего ответа, серия дней 🔥
- 📶 Работа на плохом интернете: открытые страницы доступны без сети,
  сообщения встают в очередь и уходят, когда связь вернётся

- Регистрация и вход (пароли хешируются, защита форм от CSRF)
- Лента по порядку, без алгоритмов: вкладки «Подписки» и «Все», в конце — «Ты всё посмотрел»
- Посты: создание, редактирование, удаление; лайки без перезагрузки страницы
- Обсуждение под постом + кнопка «Ответить автору в личку»
- 🔒 Близкий круг: посты, которые видят только выбранные люди
- 📷 Фото в постах и аватарки (сжимаются в WebP, хранятся в базе)
- ⏰ Отложенные посты — выходят в нужное время по часовому поясу автора
- Профили, подписки, «О себе», поиск по людям и постам
- 🔔 Уведомления о лайках, комментариях и новых подписчиках
- Личные сообщения с непрочитанными и автообновлением чата
- 🕒 Исчезающие сообщения: таймер на чат (1 час / 1 день / 7 дней)
- ⚡ Экономный режим: фото по нажатию, без автообновлений и анимаций — для слабого интернета
- PWA: «Добавить на главный экран», страница «нет сети», кэш оформления

## Запуск у себя

```bash
pip install -r web/requirements.txt
python web/import_old_data.py   # один раз: перенести старые данные из .txt и Supabase
python web/app.py               # открыть http://127.0.0.1:5000
```

Тесты: `pip install pytest && python -m pytest tests`

## Запуск на сервере

Пошаговая инструкция — в [DEPLOY.md](../DEPLOY.md). Коротко: Dockerfile в корне,
